# Product definition

## User

Software teams debugging APIs and distributed systems in any programming language.

## Core outcome

A developer can locate one failed request, understand its path through services, inspect sanitized request/response metadata and share a durable incident link without exposing secrets.

## Product areas

1. Organizations, projects, environments and role-based access.
2. API event ingestion through SDKs, OpenTelemetry and signed HTTP endpoints.
3. Trace timeline with correlated requests, logs and failures.
4. Full-text and structured search.
5. Saved queries, alert rules and notifications.
6. Safe request replay with explicit environment controls.
7. Retention, usage metering and billing.
8. Developer SDKs for TypeScript, Python, Go, Java, .NET and generic HTTP.

## Non-goals for the first milestone

- Packet capture.
- Arbitrary remote code execution.
- Recording raw credentials.
- Replacing a full APM platform.
- Production replay without a separate privileged workflow.
